# Notes for coding agents

itasca is a WebAssembly 1.0 validator in Rust verified in Lean against the
SpecTec-generated Wasm 2.0 typing rules and an explicit Wasm 1.0 profile.

Read [DEVELOPMENT.md](DEVELOPMENT.md), the
[public guarantees and trust base](README.md#formal-verification), and
[lean/README.md](lean/README.md) before changing proofs or extraction inputs.
[lean/PARITY.md](lean/PARITY.md) compares the archived Rocq version;
[UPSTREAM.md](UPSTREAM.md) tracks local toolchain/specification patches.

## Coupled sources

`src/` and `lean/Itasca/Generated/` are coupled. `Types.lean` and `Funs.lean`
are generated by `just extract` and committed. Never edit them by hand.
`FunsExternal.lean` is handwritten despite its directory. The generated
external template is ignored and must never be imported by a proof.

`lean/SpecTec/wasm2.0.lean` is generated from pinned sources and versioned
patches. Fix the source or generator, run `make -C lean spec-update`, and check
regeneration with `just spec-check`. Never patch the generated specification.

Rust remains in the verified extraction subset: no iterators, closures,
`.clone()`, bitwise operations, `String`, or new borrow/indexing patterns without
checking their extraction and proof impact. Use explicit loop counters.
DEVELOPMENT.md explains the current constraints.

## Proof discipline

Do not add axioms, `sorry`, `admit`, `native_decide`, unsafe proof shortcuts, or
kernel bypasses to solve a proof. `Itasca.Audit` rejects every axiom except
`propext`, `Classical.choice`, and `Quot.sound`. New proof modules must be
reachable through its imports; `just prove` checks this automatically. Audit
new proof-bearing adapter definitions explicitly as well as exported theorems.

Use `just check Itasca.ModuleName` for iteration, then `just prove` for the
integrated build and audit. Preserve dependency/build caches during normal
development. Scratch files belong in `$TMPDIR`, outside the proof source tree.

## Before saying you are done

- Handwritten Lean proofs/adapters: `just prove`.
- Rust or extraction inputs: `cargo test`, `cargo test --no-default-features`,
  `just extract`, `just extract-check`, and `just prove`.
- Aeneas source patches/pins: additionally `just regressions`.
- SpecTec sources/patches/pins: regenerate, `just spec-check`, and `just prove`.
- Documentation only: check links and `git diff --check`.

`just verify` runs both Rust test configurations, regenerated Rust/specification
consistency checks, toolchain regressions, and the integrated Lean build.
`just trust` reruns the transitive axiom report. Report any trust-base change.
The Rocq version is archived under `rocq-baseline`; the active branch has no
Rocq build requirement.
